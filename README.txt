VISIONIX CREATIVE V2 WEBSITE

This package is ready for Vercel.

UPLOAD TO GITHUB
1. Open your Visionix_Website repository.
2. Click Add file → Upload files.
3. Upload every file from this folder.
4. Replace existing files when GitHub asks.
5. Click Commit changes.
6. Wait about one minute for Vercel to redeploy.
7. Hard refresh using Command + Shift + R.

IMPORTANT
- Keep all images in the same main folder as index.html.
- The contact form uses FormSubmit and may ask you to verify your email after the first submission.
- Update portfolio images later with your real projects whenever ready.
