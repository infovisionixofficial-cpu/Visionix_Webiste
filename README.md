# Visionix Creative Website

A responsive one-page agency website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — menu, animations and copyright year
- `visionix-logo.png` — cropped from the logo image you supplied

## Free deployment on Vercel
1. Create a free account at Vercel.
2. Create a new GitHub repository and upload these files.
3. In Vercel, choose **Add New → Project**.
4. Import the repository.
5. Keep the default settings and click **Deploy**.

## Free deployment without GitHub
You can also deploy this folder using Netlify Drop.
